## 一、小脚本 4.86 绿色版

`小脚本4.86-绿色版.zip` 解压即用，不需要安装。

- 主程序：`小脚本4.86.exe`（编辑器 + 运行环境）
- 配套：`小脚本编程助手.exe`、插件 `插件.dll`、`eb/常用.dll`、大漠/奥迦相关 DLL
- 自带：`小脚本命令说明书.chm` + 从 CHM 解出的 938 个命令页 `chm_out/`
- 安卓相关：`adb.exe`、`AdbWinApi.dll / AdbWinUsbApi.dll`、截图工具 `scrcpy-win32-v2.7/`
- 示例脚本：`gamesfq/新建1.sfq`…（官方示例，直接拖进编辑器就能看）
- 辅助文本：`命令全集.txt`、`字库.txt`、`例子字库.txt`、`更新日志.txt`、`免责声明.txt`

**脚本写法速记**（这几点最容易踩坑）：

| 项 | 正确 | 坑 |
|---|---|---|
| 编码 | 编辑器另存为 **GBK** | UTF-8 存进去中文全乱码 |
| 注释 | `//` 单行 | — |
| 语句结束 | 分号 `;` | 漏了整段不执行 |
| 取子串 | `运算(提示=取中间文本(文本,左,右))` | 没有"文本分割"这个命令，分割文本是 `运算()` 里的函数 |
| 打印 | 先 `运算(提示=...)` 再 `调试(提示)` | `调试` 后面只接变量名，不能直接接表达式 |
| 跳转 | `标记(名字);` … `跳转标记(名字);` | 必须配对齐 |

按这些命令写的完整流程示例见 `微信加人节奏管理/加人节奏清单.sfq`。

## 三、微信加人节奏管理

**先说清楚边界：这套东西只管「什么时候加、加谁、说什么话、加完要不要跟进」，一点都不碰微信进程——不模拟按键、不注入窗口、不读内存、不自动发验证语。加人 / 通过 / 聊天全部你本人手动点。**

因为它要解决的正是"节奏像不像人"：时刻表打散不等距、间隔带随机抖动、验证语按渠道分真人话术、加完当天有跟进清单。

### 三步跑起来

需要系统 Python（要 openpyxl 导出 xlsx）：`C:/Python314/python.exe`

```bash
cd 微信加人节奏管理

# 1) 排今天的时刻表（不等距随机打散，全局最小间隔 4 分钟）
C:/Python314/python.exe planner.py plan

# 2) 到点了按提醒手动去加，加完登记
C:/Python314/python.exe planner.py add --序号 1 --通过        # 已通过
C:/Python314/python.exe planner.py add --序号 2             # 只发出验证，还没回

# 3) 第二天看哪些人通过了、该跟进谁
C:/Python314/python.exe planner.py followup --通过 3
C:/Python314/python.exe planner.py sheet                    # 导出加人台账.xlsx
```

其他命令：`run`（打印今日清单）、`status`（看当前进度）、`load xxx.xlsx`（批量导入名单）。
`planner.py --help` 看全参数。字段、重复判定、导入别名见 `微信加人节奏管理/README.md`。

### 台账字段

| 列 | 说明 |
|---|---|
| 日期 / 时段 / 序号 | 排期信息 |
| 渠道 | 从哪来的（抖音 / 小区群 / 转介绍…），决定验证语文案 |
| 目标 | 姓名 |
| 微信号 | 用微信号搜 |
| 联系电话 | 用手机号搜 |
| 对方昵称备注 | 对方通过后自己改的备注，**留一列给你事后写** |
| 验证语 | 真人来源感，导入时**留空不自动填**，自己写 |
| 发出时间 / 通过时间 | 时间戳 |
| 状态 | 待发 / 已发 / 待通过 / 已通过 / 已跟进 |
| 跟进备注 | 聊了什么、聊死了没有 |

### 关于 `.sfq` 参考脚本

`加人节奏清单.sfq` 是**按手册中文命令语法写的范文**：读名单 → 逐条打印「该加谁／用哪个号搜／说什么」→ 随机等一会儿。它只 `调试` 打印、只 `写到文件`，全文没有任何"后台按键 / 模拟按键 / 打开进程 / 找图"这类窗口操作命令，所以运行它不构成"第三方程序操控微信客户端"。

想确认它没藏东西：

```bash
C:/Python314/python.exe check_sfq.py 加人节奏清单.sfq     # 括号配对 + 命令白名单
C:/Python314/python.exe simulate_sfq.py 加人节奏清单.sfq 15   # 模拟跑前 15 行
```

## 两件你必须先看的话

**1. 合规风险不是"节奏伪装"能解决的。**
用第三方脚本操控微信客户端加好友，本身就落在《微信个人账号使用规范》1.1.2.4 / 1.1.2.6 的禁止范围内（外挂、非授权第三方工具接入）。已有判例因批量外挂加人判赔数百万元。
微信风控不只看操作节奏，还看"客户端里是不是跑着第三方程序"——这一层跟你的操作像不像人完全无关。
**本仓库的微信相关工具刻意做成"只提醒你手动去加"，就是为了保证这条红线不被踩。** 用不用、用多少，你自己判断，后果自负。

**2. 台账里有手机号和微信号，别外传。**
`加人台账.xlsx / .csv`、`名单.txt`、`planner_config.json` 都含个人信息。公开仓库上传前确认已经换成假数据；真数据只留本地。仓库里那几行示例数据记得删掉再公开。
